# Security Policy

## Supported Versions

| Version | Supported                                     |
| ------- | --------------------------------------------- |
| 6.x     | Yes                                           |
| 5.x     | Security fixes until 6.0.0 stable is released |
| < 5     | No                                            |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting:
https://github.com/yahoo/ember-gridstack/security/advisories/new

Do not open public issues or pull requests for security vulnerabilities.
We will respond in the advisory and coordinate a fix and disclosure with you.
